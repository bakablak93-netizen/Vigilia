# VIGILIA — Intelligent Bank Defense Laboratory

**Test the defense before the threat.**  
*We don't just detect fraud. We test the systems designed to stop it.*

VIGILIA is an isolated synthetic testing laboratory for banking anti-fraud rule evaluation, stress testing, and closed-loop **Defense Evolution**, developed for **BCC Hackathon 2026**.

> **Disclaimer:** VIGILIA operates exclusively on synthetic virtual customers and synthetic transactions generated by its Virtual Bank Simulator. It does not use real personal or banking data and does not connect to or test live Bank CenterCredit infrastructure.

---

## Core Architecture

1. **Virtual Bank Simulator (`backend/app/services/simulator.py`)**  
   Reproducible generator (seeded RNG) creating virtual retail/business customer profiles and 5 realistic transaction scenarios:
   - **A. Normal Activity**
   - **B. Unusual Transaction Amount** (includes both legitimate large payments and risky outliers)
   - **C. New Recipient Risk** (new payees with contextual signals)
   - **D. Duplicate Payment** (rapid retries vs replay attacks)
   - **E. Suspicious Transaction Sequence** (nocturnal/structuring bursts vs legitimate B2B batches)  
   Transactions are deterministically split into `calibration` (20%), `validation` (40%), and `evaluation` (40%) slices so rules are never tuned on the held-out evaluation split.

2. **Defense Engine (`backend/app/services/defense_engine.py`)**  
   Configurable, transparent rule engine (0–100 `risk_score`, `low`/`medium`/`high`/`critical` levels, causal prior history). Strictly blind to `ground_truth_label` and `scenario_type`. Supports immutable configuration versioning (`Defense v1.0`, `v1.1`, ...).

3. **Evaluation Engine (`backend/app/services/evaluation_engine.py`)**  
   Computes TP, FP, TN, FN, Precision, Recall, F1, FPR, FNR, Confusion Matrix, per-scenario breakdown, and per-rule trigger precision with zero-division safety.

4. **AI Security Analyst (`backend/app/services/ai_analyst.py`)**  
   Deterministic diagnostics inspecting actual False Negatives and False Positives to explain missed risks and false blocks and propose bounded rule changes. Optionally supports an external OpenAI-compatible LLM via `VIGILIA_LLM_API_KEY` and `VIGILIA_LLM_BASE_URL` without fabricating metrics.

5. **Defense Evolution (`backend/app/services/defense_evolution.py`)**  
   6-step workflow:
   1. Baseline Test (`validation` split)
   2. Weakness Detection (`validation` split)
   3. Recommendation Generation
   4. Candidate Validation (creates new immutable Defense version and tests on `validation` split)
   5. Before / After Comparison
   6. Final Held-Out Evaluation (`evaluation` split) with honest verdict (`improved`, `mixed`, or `rejected_regression`)

6. **SQLite Persistence & Reports (`backend/app/models.py`, `backend/app/services/reports.py`)**  
   Stores datasets, customers, transactions, defense configurations, experiments, transaction-level results, recommendations, and evolution runs, with JSON and CSV report export.

7. **Frontend Laboratory UI (`frontend/`)**  
   React + TypeScript + Vite + Tailwind CSS + Recharts + TanStack Query + React Router, featuring 7 sections (`Overview`, `Simulation Lab`, `Defense Engine`, `Defense Evolution`, `AI Analyst`, `Reports`, `Settings`) and RU / KZ / EN localization.

## Running on Windows

### Prerequisites
- Python 3.11+
- Node.js 18+

### 1. Backend Setup
```powershell
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

### 2. Frontend Setup
```powershell
cd frontend
npm install
```

### 3. Launch Both Services
Run `START_WINDOWS.bat` from the repository root, or start manually in two terminals:

**Terminal 1 (Backend on port 8001):**
```powershell
cd backend
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

**Terminal 2 (Frontend on port 5173):**
```powershell
cd frontend
npm run dev -- --port 5173
```

- Frontend UI: `http://localhost:5173`
- Backend API: `http://localhost:8001`
- OpenAPI Docs: `http://localhost:8001/docs`
